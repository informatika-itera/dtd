Apa Itu Spreadsheet?

📊

Spreadsheet

Aplikasi pengolah data berupa tabel baris & kolom untuk perhitungan, analisis, dan visualisasi

📘

Microsoft Excel

Program spreadsheet paling populer, bagian dari Microsoft Office / Microsoft 365

📗

Google Sheets

Spreadsheet berbasis cloud dari Google, gratis & bisa kolaborasi real-time

📝

Komponen Dasar

Cell (sel), Baris (1, 2, 3…), Kolom (A, B, C…), Sheet (tab), Workbook (file)

Sel Referensi
Setiap sel punya alamat unik: kolom + baris. Contoh: A1 = kolom A, baris 1. D15 = kolom D, baris 15.

Format Sel: Number, Currency, Date, %

🔢

Number (Angka)

Mengatur jumlah desimal, pemisah ribuan. Contoh: 1.234,56

💰

Currency (Mata Uang)

Simbol Rp / $ + format angka. Contoh: Rp 1.500.000

📅

Date (Tanggal)

Berbagai format: DD/MM/YYYY, 5 Agustus 2026, dll.

%

Percentage (%)

Angka dikali 100 + tanda %. Contoh: 0,85 → 85%

Cara Memformat
Pilih sel → Home > Number Format (Excel) atau Format > Number (Sheets). Shortcut: Ctrl+1 untuk membuka dialog format.

Sortir & Filter Data

Sort (Urutkan)

Sort Ascending (A→Z)
Mengurutkan data dari kecil ke besar / A ke Z. Berguna untuk melihat urutan abjad atau angka terkecil dulu.
Sort Descending (Z→A)
Mengurutkan dari besar ke kecil / Z ke A. Cocok untuk melihat nilai tertinggi atau penjualan terbanyak.

Filter (Saring)

AutoFilter
Menyaring data berdasarkan kriteria tertentu tanpa menghapus baris lain. Aktifkan: Data > Filter atau Ctrl+Shift+L.

Validasi Data

Data Validation membatasi apa yang boleh dimasukkan ke dalam sel — mencegah kesalahan input.

Contoh Aturan
• Hanya angka antara 1 – 100
• Tanggal dalam rentang tertentu
• Pilihan dari dropdown list
• Teks dengan panjang maksimal
Pesan Error Kustom
Tampilkan pesan saat input tidak valid, misalnya: “Nilai harus antara 1–100!”

Proteksi Sheet

Melindungi sheet agar rumus & data penting tidak terhapus atau berubah secara tidak sengaja.

Lock Cell
Secara default semua sel terkunci. Buka kunci sel tertentu yang boleh diedit orang lain sebelum mengaktifkan proteksi.
Protect Sheet
Excel: Review → Protect Sheet → set password.
Sheets: Data → Protect Sheets and Ranges → pilih range.
Kapan Digunakan?
Template formulir, laporan keuangan, nilai mahasiswa — data yang tidak boleh dimodifikasi sembarang orang.

Rumus Dasar Spreadsheet

Σ

SUM

Menjumlahkan seluruh nilai dalam range

=SUM(A1:A10)

x̄

AVERAGE

Menghitung rata-rata dari range

=AVERAGE(A1:A10)

↑

MAX

Mencari nilai terbesar dalam range

=MAX(A1:A10)

↓

MIN

Mencari nilai terkecil dalam range

=MIN(A1:A10)

#

COUNT

Menghitung jumlah sel yang berisi angka

=COUNT(A1:A10)

Aa

COUNTA

Menghitung sel yang tidak kosong (termasuk teks)

=COUNTA(A1:A10)

Relatif vs Absolut

Referensi Relatif
A1 — berubah saat rumus disalin. Contoh: rumus di B1 =SUM(A1:A5), saat disalin ke B2 otomatis menjadi =SUM(A2:A6).
Referensi Absolut
$A$1 — tetap / tidak berubah saat disalin. Tanda $ mengunci kolom dan baris.
Referensi Campuran
$A1 — kolom terkunci, baris berubah.
A$1 — baris terkunci, kolom berubah.

Relatif

A1 → salin → berubah

↓

Absolut

$A$1 → salin → tetap

Charts & Grafik

📊

Bar Chart

Membandingkan nilai antar kategori. Cocok untuk data penjualan per bulan, nilai per mata kuliah.

📈

Line Chart

Menampilkan tren perubahan data dari waktu ke waktu. Cocok untuk grafik pertumbuhan, suhu, saham.

🥧

Pie Chart

Menampilkan proporsi bagian dari keseluruhan. Cocok untuk distribusi persentase.

Cara Membuat Grafik
Pilih data → Insert → Chart (Excel) atau Insert → Chart (Sheets) → pilih tipe grafik → sesuaikan warna, label, dan judul.
