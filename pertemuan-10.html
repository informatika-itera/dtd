Header, Footer & Page Numbering

Apa Itu Header & Footer?
Area di atas (header) dan bawah (footer) setiap halaman yang otomatis muncul di semua halaman. Bisa berisi nomor halaman, judul dokumen, nama penulis, atau tanggal.

Cara menambahkan: Insert → Headers & footers → Header (atau Footer). Klik area header/footer untuk mulai mengedit.

Gunakan Insert → Page numbers untuk menambahkan nomor halaman otomatis di posisi yang diinginkan.

Tips
Centang "Different first page" pada area header/footer untuk menyembunyikannya di halaman pertama (cover).

Page Numbering & Section Break

🔢

Page Number

Insert → Page numbers → pilih posisi (kiri/kanan header atau footer) atau More options

📐

Format Angka

Angka (1,2,3) atau Romawi (i,ii,iii) via More options

✂️

Section Break

Insert → Break → Section break (next page). Membagi dokumen menjadi section berbeda

🔗

Unlink Header

Hapus centang "Link to previous" di header/footer tiap section agar berbeda

Watermark & Page Border

💧 Watermark

  • Insert → Watermark → pilih Teks atau Gambar
  • Bisa teks ("DRAFT", "RAHASIA") atau gambar (logo)
  • Atur skala, transparansi, dan posisi di panel samping
  • Tampil di belakang teks pada semua halaman
  • Berguna untuk menandai status dokumen

🖼️ Page Border

  • Tidak ada menu Page Borders di Docs — gunakan tabel 1×1 atau Drawing
  • Atur garis & warna via Table properties atau Drawing
  • Atur style garis (solid, dashed, double)
  • Warna dan ketebalan bisa dikustomisasi
  • Atur posisinya ke Behind text agar jadi bingkai latar

Pengaturan Cetak & Export PDF

🖨️ Pengaturan Print

  • Print Range — semua halaman, halaman tertentu, atau seleksi
  • Copies — jumlah salinan yang dicetak
  • Orientation — portrait atau landscape
  • Paper size — A4, Letter, Legal, dll.
  • Tekan Ctrl + P untuk preview sebelum mencetak

📄 Export ke PDF

  • File → Download → PDF Document (.pdf) — format tetap, standar industri
  • Batasi akses buka dokumen via tombol Share (Viewer / Commenter / Editor)
  • Alternatif: File → Print → tujuan "Save as PDF"

Fitur Kolaborasi & Template

💬 Comments
Insert → Comment (atau Ctrl + Alt + M). Tambahkan catatan tanpa mengubah isi dokumen.
📝 Mode Suggesting
Mode Suggesting (dropdown Editing, kanan atas). Semua perubahan ditandai — bisa diterima atau ditolak satu per satu.
📋 Template
Buka docs.google.com → Template gallery → pilih template (surat, laporan, CV). Template sudah punya format dan layout siap pakai.

Tugas Praktikum: Sitasi & Dokumen Terstruktur

Tugas (±30 menit)
Buat dokumen akademik singkat dengan sitasi & daftar pustaka, lengkapi dengan header/footer, daftar isi, dan watermark — dikerjakan mandiri selama kelas.
Langkah 1–4
Langkah 5–8
1

Buat dokumen

Buka docs.google.com → Blank document, beri nama DTD_P10_NIM_NAMA.

5

Header & footer

Insert → Headers & footers → Header berisi judul; footer: Insert → Page numbers.

2

Struktur konten

Tulis 2 paragraf bertopik "Manfaat Teknologi Digital" dengan judul bagian memakai Heading 1.

6

Daftar isi

Letakkan kursor di atas dokumen, lalu Insert → Table of contents.

3

Tambah sitasi

Tools → Citations → pilih gaya APA → + Add citation source (minimal 1 buku via ISBN dan 1 website via URL).

7

Sisipkan daftar pustaka

Klik Cite pada sumber di paragraf, lalu Insert bibliography di akhir dokumen.

4

Watermark

Insert → Watermark → pilih Teks, ketik "DRAFT", atur transparansi.

8

Export & kumpulkan

File → Download → PDF Document (.pdf), lalu share link dokumen ke dosen.

Kriteria Pengumpulan
Nama dokumen sesuai format, minimal 2 sitasi (buku & website), daftar pustaka otomatis, header/footer + nomor halaman, TOC dari heading, watermark DRAFT, dan tautan share berfungsi.
