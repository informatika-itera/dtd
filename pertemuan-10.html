Header, Footer & Page Numbering

Apa Itu Header & Footer?
Area di atas (header) dan bawah (footer) setiap halaman yang otomatis muncul di semua halaman. Bisa berisi nomor halaman, judul dokumen, nama penulis, atau tanggal.

Cara menambahkan: Insert → Header & Footer di ribbon. Klik area header/footer untuk mulai mengedit.

Gunakan Page Number untuk menambahkan nomor halaman otomatis di posisi yang diinginkan.

Tips
Centang "Different First Page" untuk menyembunyikan header/footer di halaman pertama (cover).

Page Numbering & Section Break

🔢

Page Number

Insert → Page Number. Posisi: atas, bawah, margin, atau posisi kursor

📐

Format Angka

Angka (1,2,3), Romawi (i,ii,iii), atau huruf (a,b,c)

✂️

Section Break

Layout → Breaks → Next Page. Membagi dokumen menjadi section berbeda

🔗

Unlink Header

Putuskan link antar section agar setiap section punya header/footer berbeda

Watermark & Page Border

💧 Watermark

  • Design → Watermark → Custom Watermark
  • Bisa teks ("DRAFT", "RAHASIA") atau gambar (logo)
  • Atur ukuran, warna, dan transparansi
  • Tampil di belakang teks pada semua halaman
  • Berguna untuk menandai status dokumen

🖼️ Page Border

  • Design → Page Borders
  • Pilih Box, Shadow, 3-D, atau Custom
  • Atur style garis (solid, dashed, double)
  • Warna dan ketebalan bisa dikustomisasi
  • Bisa ditambahkan Art Border dekoratif

Pengaturan Cetak & Export PDF

Pengaturan Print

PengaturanFungsi
Print RangeSemua halaman, halaman tertentu, atau seleksi
CopiesJumlah salinan yang dicetak
DuplexCetak bolak-balik (manual/otomatis)
OrientationPortrait (vertikal) atau Landscape (horizontal)
Paper SizeA4, Letter, F4, Legal, dll.

Export ke PDF

📄 Save As PDF
File → Export → Create PDF/XPS. Format tetap, tidak bisa diedit sembarangan, standar industri.
🔒 PDF Terproteksi
Bisa diatur password agar hanya orang tertentu yang bisa membuka dokumen.
🖨️ Preview Sebelum Cetak
Tekan Ctrl + P untuk melihat preview dan memastikan layout sebelum mencetak.

Fitur Kolaborasi & Template

💬 Comments
Review → New Comment. Tambahkan catatan tanpa mengubah isi dokumen.
📝 Track Changes
Review → Track Changes. Semua perubahan ditandai — bisa diterima atau ditolak satu per satu.
📋 Template
File → New → Pilih template profesional (surat, laporan, CV). Template sudah punya format dan layout siap pakai.
