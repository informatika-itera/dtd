Fungsi IF

Fungsi IF menguji suatu kondisi dan mengembalikan nilai berdasarkan hasil uji tersebut — TRUE atau FALSE.

Sintaks
=IF(kondisi; nilai_jika_TRUE; nilai_jika_FALSE)
Contoh
Jika nilai ≥ 70 maka "Lulus", jika tidak "Tidak Lulus":
=IF(A1>=70; "Lulus"; "Tidak Lulus")

Parameter kondisi bisa menggunakan operator perbandingan: =, >, <, >=, <=, <> (tidak sama dengan).

Kondisi?

A1 ≥ 70?

→

TRUE

"Lulus" ✓

→

FALSE

"Tidak Lulus" ✗

Nested IF (IF Bersarang)

Menyusun beberapa IF di dalam satu formula untuk menguasi banyak kondisi sekaligus — seperti membuat grading otomatis.

Sintaks Nested IF
=IF(kondisi1; nilai1; IF(kondisi2; nilai2; IF(kondisi3; nilai3; nilai_default)))
Contoh: Grading Nilai
=IF(A1>=85;"A";IF(A1>=70;"B";IF(A1>=55;"C";"D")))

A1=90 → A  |  A1=75 → B  |  A1=60 → C  |  A1=40 → D

Tip: Bisa juga menggunakan IFS() di Google Sheets / Excel 365 sebagai alternatif yang lebih rapi.

COUNTIF & SUMIF

🔢

COUNTIF

Menghitung jumlah sel yang memenuhi kriteria tertentu.

Sintaks
=COUNTIF(range; kriteria)

Contoh: Hitung jumlah siswa yang lulus (nilai ≥ 70):

=COUNTIF(B2:B50; ">=70")

➕

SUMIF

Menjumlah nilai-nilai yang memenuhi kriteria tertentu.

Sintaks
=SUMIF(range_kriteria; kriteria; range_jumlah)

Contoh: Jumlah penjualan produk "Laptop":

=SUMIF(A2:A100; "Laptop"; C2:C100)

VLOOKUP

Vertical Lookup — mencari nilai di kolom pertama tabel, lalu mengambil nilai dari kolom lain pada baris yang sama.

Sintaks
=VLOOKUP(kolom_cari; tabel; kolom_index; [pencocokan])
Parameter
kolom_cari — nilai yang ingin dicari
tabel — range tabel referensi
kolom_index — nomor kolom yang ingin diambil (mulai dari 1)
pencocokan — FALSE (exact match) atau TRUE (approximate)
Contoh
Cari harga produk berdasarkan kode:
KodeProdukHarga
P001Laptop8.500.000
P002Mouse150.000
P003Keyboard350.000
=VLOOKUP("P002"; A2:C4; 3; FALSE)
Hasil: 150.000

HLOOKUP

Horizontal Lookup — mencari nilai di baris pertama tabel, lalu mengambil nilai dari baris lain pada kolom yang sama.

Sintaks
=HLOOKUP(baris_cari; tabel; baris_index; [pencocokan])
Kapan Pakai?
Gunakan HLOOKUP ketika data tersusun secara horizontal — header (label) berada di baris pertama, bukan kolom pertama.

Jika data vertikal → pakai VLOOKUP.
Jika data horizontal → pakai HLOOKUP.
Contoh
Cari nilai UTS mata kuliah "Matematika":
MatematikaFisikaKimia
UTS857890
UAS928088
=HLOOKUP("Matematika"; A1:D3; 1; FALSE)
Hasil: 85

INDEX & MATCH

Kombinasi INDEX dan MATCH adalah alternatif fleksibel untuk VLOOKUP — bisa mencari ke kiri, tidak terbatas kolom pertama.

MATCH — mencari posisi
=MATCH(nilai_cari; range; 0)
INDEX — mengambil nilai
=INDEX(range; baris; kolom)
Kombinasi INDEX + MATCH
=INDEX(kolom_diambil; MATCH(nilai_cari; kolom_cari; 0))
Contoh: Cari Nama dari ID
NamaID
Budi101
Ani102
Citra103
=INDEX(A2:A4; MATCH(102; B2:B4; 0))
Hasil: Ani

Kelebihan: Kolom yang dicari (ID) ada di kanan kolom hasil (Nama) — VLOOKUP tidak bisa!

Praktik: Menerapkan Rumus pada Data Penjualan

🎯 IF — Status Penjualan Besar

Tandai transaksi ≥ Rp 5 juta sebagai "Besar":

=IF(G2>=5000000;"Besar";"Biasa")

📊 COUNTIF — Jumlah per Kategori

Hitung berapa kali muncul kategori "Komputer":

=COUNTIF(D2:D100;"Komputer")

➕ SUMIF — Total per Produk

Jumlahkan pendapatan dari "Laptop ASUS":

=SUMIF(C2:C100;"Laptop ASUS";G2:G100)

🔍 VLOOKUP — Cari Harga Produk

Ambil harga satuan dari tabel master:

=VLOOKUP("Mouse Logitech";Master!A:C;3;FALSE)

Rangkuman

Poin-Poin Penting Pertemuan 12

1
IF menguji kondisi TRUE/FALSE untuk mengembalikan nilai tertentu. Nested IF memungkinkan pengujian banyak kondisi sekaligus.
2
COUNTIF menghitung jumlah sel sesuai kriteria, sedangkan SUMIF menjumlahkan nilai berdasarkan kriteria tertentu.
3
VLOOKUP mencari data secara vertikal (kolom pertama), sementara HLOOKUP mencari secara horizontal (baris pertama).
4
Kombinasi INDEX + MATCH lebih fleksibel daripada VLOOKUP karena bisa mencari ke arah mana pun, termasuk ke kiri.
5
Semua fungsi ini diterapkan secara nyata pada data penjualan untuk menghitung, mencari, dan menganalisis data secara otomatis.
