Fungsi String: LEFT, RIGHT, MID

LEFT(teks, n)
Mengambil n karakter dari kiri. Contoh: LEFT("Jakarta", 3) → Jak
RIGHT(teks, n)
Mengambil n karakter dari kanan. Contoh: RIGHT("Jakarta", 3) → rta
MID(teks, mulai, n)
Mengambil n karakter dari posisi tertentu. Contoh: MID("Jakarta", 2, 3) → aka

Fungsi Tanggal: TODAY, YEAR, MONTH, DAY

TODAY()
Menampilkan tanggal hari ini secara otomatis. Selalu update saat file dibuka.
YEAR(tanggal)
Mengambil tahun dari nilai tanggal. YEAR(A1) → 2026
MONTH(tanggal) & DAY(tanggal)
Mengambil bulan atau hari dari tanggal.
DATE(tahun, bulan, hari)
Membuat tanggal dari komponen terpisah. DATE(2026,12,25) → 25/12/2026
Anatomi Tanggal di Excel
FungsiHasil

YEAR(TODAY())2026
MONTH(TODAY())8
DAY(TODAY())5
WEEKDAY(TODAY())4 (Rabu)

Tabel Pivot: Konsep Dasar

Pivot Table adalah fitur Excel untuk meringkas, menganalisis, dan menjelajahi data besar secara interaktif — tanpa rumus manual.

📋

Baris (Rows)

Kategori data yang ditampilkan per baris, misal: nama departemen

📊

Nilai (Values)

Data numerik yang dijumlahkan, dihitung rata-rata, dll.

📑

Kolom (Columns)

Pemisah data berdasarkan kategori, misal: kuartal atau bulan

🔽

Filter

Menyaring data yang ditampilkan tanpa mengubah sumber

Praktik: Membuat Pivot Table

Langkah 1 — Siapkan Data
Pilih range data. Pastikan ada header kolom yang jelas dan tidak ada baris kosong.
Langkah 2 — Insert PivotTable
Klik Insert → PivotTable. Pilih lokasi output (sheet baru atau yang sama).
Langkah 3 — Drag Fields
Seret field ke area Rows, Columns, Values, Filters di panel kanan.
Langkah 4 — Atur Ringkasan
Ubah dari Sum ke Count, Average, Max, Min sesuai kebutuhan analisis.
Contoh Ringkasan Pivot

Pengenalan Macro & VBA

Macro adalah rekaman perintah yang bisa diputar ulang. VBA (Visual Basic for Applications) adalah bahasa pemrograman di balik macro Excel.

🎬

Macro

Sekuens perintah yang direkam dan bisa dijalankan berulang kali

⌨️

VBA

Bahasa pemrograman untuk membuat macro yang lebih kompleks dan fleksibel

⚡

Otomatisasi

Tugas berulang seperti format, filter, dan laporan bisa diotomasi

🔒

Keamanan

File macro disimpan sebagai .xlsm, bukan .xlsx

Pertemuan 13 — Dasar Teknologi Digital8 / 14

Merekam Macro

Langkah 1
Buka tab View → Macros → Record Macro. Beri nama tanpa spasi (misal: FormatLaporan).
Langkah 2
Opsional: tentukan shortcut key (misal: Ctrl+Shift+F).
Langkah 3
Lakukan semua langkah yang ingin direkam — format, rumus, navigasi.
Langkah 4
Klik View → Macros → Stop Recording. Macro siap dijalankan!
Contoh Kode VBA
Sub FormatLaporan()
  Range("A1:D1").Font.Bold = True
  Range("A1:D1").Interior.Color = vbGreen
  Columns("A:D").AutoFit
End Sub

📧

Kirim Email

📊

Buat Grafik
