Proses & kirim balasan

Paket Data

  • Data dipecah menjadi paket-paket kecil
  • Setiap paket punya header (alamat tujuan)
  • Paket bisa lewat jalur berbeda
  • Disusun ulang di tujuan oleh TCP

Routing

  • Router membaca alamat IP tujuan
  • Memilih jalur tercepat/terdekat
  • BGP mengatur routing antar ISP
  • Setiap hop = satu router

Basis Data: SQL vs NoSQL

Apa itu Basis Data?
Sistem untuk menyimpan, mengelola, dan mengambil data secara terstruktur dan efisien.

SQL (Relasional)

  • Tabel dengan baris & kolom
  • Skema tetap (rigid)
  • Query bahasa SQL
  • Contoh: data mahasiswa ITERA

MySQL, PostgreSQL, Oracle

NoSQL (Non-Relasional)

  • Dokumen, key-value, graf
  • Skema fleksibel
  • Skalabilitas horizontal
  • Contoh: data postingan Instagram

MongoDB, Redis, Cassandra

Kapan Memilih?
Butuh konsistensi ketat → SQL. Butuh fleksibilitas & skala besar → NoSQL. Banyak sistem modern menggunakan keduanya (polyglot persistence).

Dampak Positif & Negatif

✅ Dampak Positif

  • 🌍 Koneksi global — komunikasi tanpa batas geografis
  • 🛒 UMKM naik kelas — GoFood, Tokopedia, Shopee
  • 📚 Edukasi online — akses materi dari mana saja
  • 📢 Gerakan sosial — #MeToo, fundraising, awareness

⚠️ Tantangan

  • 📰 Misinformasi — hoaks menyebar 6x lebih cepat
  • 😢 Cyberbullying — dampak psikologis nyata
  • 🕐 Kecanduan — scroll tanpa henti, FOMO
  • 🔒 Privasi data — data pribadi disalahgunakan
Fakta Indonesia
UMKM di Indonesia naik kelas lewat platform digital (GoFood, Tokopedia). Tapi hoaks juga menyebar cepat lewat WhatsApp — UU ITE hadir untuk mengatur etika digital.

Keamanan Bermedia Sosial

🔐

Password Kuat + 2FA
Minimal 12 karakter, gabungan huruf+angka+simbol. Aktifkan autentikasi dua faktor

✅

Cek Fakta Sebelum Share
Periksa sumber, cari di situs fact-check. Jangan sebar hoaks

🎣

Waspadai Phishing
Jangan klik link mencurigakan. "Paket gagal dikirim" via WhatsApp = modus penipuan

👁️

Atur Privasi Akun
Siapa yang bisa lihat postinganmu? Review izin aplikasi secara berkala

Ingat
Keamanan digital dimulai dari kebiasaan kecil sehari-hari. Satu klik ceroboh bisa berdampak besar.

Rangkuman Pertemuan 3

1
Internet adalah jaringan global yang menghubungkan miliaran perangkat melalui protokol TCP/IP dan DNS.
2
Data di internet dikirim dalam paket-paket kecil yang dirutekan melalui berbagai jalur oleh router.
3
Cloud computing memungkinkan akses sumber daya komputasi (storage, computing, real-time) tanpa infrastruktur lokal.
4
Website dibangun dari HTML (struktur), CSS (tampilan), dan JavaScript (interaksi). Basis data: SQL untuk relasional, NoSQL untuk fleksibel.
5
Media sosial punya dampak positif (koneksi, UMKM, edukasi) dan negatif (hoaks, cyberbullying, kecanduan).
6
Literasi digital & keamanan bermedia sosial — berpikir kritis, cek fakta, password kuat, atur privasi.
