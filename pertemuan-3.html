Proses & kirim balasan

Paket Data

  • Data dipecah menjadi paket-paket kecil
  • Setiap paket punya header (alamat tujuan)
  • Paket bisa lewat jalur berbeda
  • Disusun ulang di tujuan oleh TCP

Routing

  • Router membaca alamat IP tujuan
  • Memilih jalur tercepat/terdekat
  • BGP mengatur routing antar ISP
  • Setiap hop = satu router

Basis Data: SQL vs NoSQL

Apa itu Basis Data?
Sistem untuk menyimpan, mengelola, dan mengambil data secara terstruktur dan efisien.

SQL (Relasional)

  • Tabel dengan baris & kolom
  • Skema tetap (rigid)
  • Query bahasa SQL
  • Contoh: MySQL, PostgreSQL

NoSQL (Non-Relasional)

  • Dokumen, key-value, graf
  • Skema fleksibel
  • Skalabilitas horizontal
  • Contoh: MongoDB, Redis

Perbandingan SQL vs NoSQL

AspekSQLNoSQL
StrukturTabel baris & kolomDokumen, graf, key-value
SkemaTetap (schema-on-write)Fleksibel (schema-on-read)
SkalabilitasVertikal (naik spesifikasi)Horizontal (tambah node)
KonsistensiACID (ketat)BASE (eventual)
Contoh KasusBanking, e-commerceIoT, big data, real-time
Kapan Memilih?
Butuh konsistensi ketat → SQL. Butuh fleksibilitas & skala besar → NoSQL. Banyak sistem modern menggunakan keduanya (polyglot persistence).

Literasi Digital

🔍

Cari & Verifikasi

Cek fakta sebelum membagikan. Gunakan sumber terpercaya

🛡️

Keamanan Digital

Password kuat, 2FA, waspada phishing & social engineering

⚖️

Etika Digital

Hormati privasi, hindari cyberbullying, hormati hak cipta

🧠

Berpikir Kritis

Kenali bias algoritma, filter bubble, dan echo chamber

Mengapa Penting?
Literasi digital bukan hanya kemampuan teknis — ini tentang berpikir kritis terhadap informasi, melindungi diri di dunia maya, dan berpartisipasi secara bertanggung jawab dalam masyarakat digital.
