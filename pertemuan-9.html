Apa Itu Pengolah Kata?

Definisi
Pengolah kata (word processor) adalah aplikasi untuk membuat, mengedit, memformat, dan mencetak dokumen berbasis teks.

Google Docs Microsoft Word LibreOffice Writer WPS Writer Pages (macOS)

Format Teks Dasar

🔤

Jenis Huruf (Font)

Pilih font untuk mengatur karakter teks. Serif (Times New Roman) untuk dokumen formal, Sans-serif (Arial, Roboto) untuk modern.

📐

Ukuran & Gaya

Atur ukuran (pt), tebal (bold), miring (italic), garis bawah (underline), dan highlight.

↔️

Perataan (Alignment)

Rata kiri, rata kanan, rata tengah, atau rata kiri-kanan (justify) untuk tampilan rapi.

Tips
Gunakan ukuran 11–12 pt untuk isi dokumen, 14–16 pt untuk sub-judul, dan 18–24 pt untuk judul utama.

Layout Halaman

📏

Margin

Jarak tepi teks ke pinggir kertas. Default Google Docs: 1 inci (2,54 cm) untuk semua sisi. Ubah via File → Page setup.

🔄

Orientasi

Portrait (vertikal) untuk dokumen biasa. Landscape (horizontal) untuk tabel lebar atau poster.

📄

Ukuran Kertas

A4 (21 × 29,7 cm) standar Indonesia. Letter (21,6 × 27,9 cm) standar Amerika. F4 (21,5 × 33 cm) memerlukan ukuran kustom atau add-on (tidak tersedia bawaan).

Akses Layout
File → Page setup → atur margin, orientasi, dan ukuran kertas.

Menyisipkan Objek

🖼️

Gambar

Sisipkan foto atau ilustrasi dari file atau online. Atur perataan teks: In line, Wrap text, atau Break text.

📊

Tabel

Organisasi data dalam baris & kolom. Pilih jumlah baris × kolom, lalu format warna & border.

⬡

Bentuk (Shapes)

Buat via Insert → Drawing → New (bentuk, panah, callout), lalu Save and close.

📈

Grafik (Chart)

Bar, column, line, pie. Dibuat di Google Sheets, lalu disisipkan via Insert → Chart → From Sheets.

Page Break & Section Break

Page Break
Memaksa teks lanjut ke halaman baru. Shortcut: Ctrl + Enter. Berguna sebelum bab baru atau daftar pustaka.
Section Break
Membagi dokumen menjadi bagian independen. Disisipkan via Insert → Break. Setiap section bisa punya orientasi dan header/footer berbeda.
TipeFungsi
Section break (next page)Section baru dimulai di halaman baru
Section break (continuous)Section baru di halaman yang sama

Styles & Headings

🏷️

Styles

Format teks yang sudah didefinisikan sebelumnya (Title, Subtitle, Heading 1–6, Normal text). Memastikan konsistensi format di seluruh dokumen.

Title Subtitle Heading 1 Heading 2 Heading 3 Normal text
📑

Table of Contents

Dengan menerapkan Styles judul (Heading 1, 2, 3), Google Docs bisa otomatis membuat Daftar Isi (Table of Contents) yang bisa di-update.

Cara
Insert → Table of contents → pilih dengan nomor halaman atau tautan biru.

Tugas Praktikum: Dokumen Digital Pertama

Tugas (±30 menit)
Buat dokumen Google Docs rapi yang menerapkan format teks, layout halaman, dan penyisipan objek — dikerjakan mandiri selama kelas.
Langkah 1–4
Langkah 5–8
1

Buat dokumen baru

Buka docs.google.com → pilih Blank document. Ganti nama dokumen menjadi DTD_P09_NIM_NAMA (contoh: DTD_P09_12212345_Budi).

5

Sisipkan tabel

Masukkan tabel minimal 3 kolom × 2 baris (1 baris judul + 1 baris data) berisi data sederhana, mis. daftar mata kuliah.

2

Ketik konten

Tulis 3–5 kalimat dengan topik "Manfaat Teknologi Digital dalam Perkuliahan".

6

Sisipkan gambar & penekanan

Tambahkan 1 gambar dengan perataan Wrap text. Tebalkan kata kunci dan beri highlight pada istilah penting.

3

Terapkan Styles

Baris judul pakai Heading 1; paragraf isi pakai Normal text ukuran 11–12 pt.

7

Atur akses berbagi

Klik tombol Share (kanan atas) → pada General access pilih Anyone with the link → biarkan role Viewer → klik Done.

4

Atur layout

Buka File → Page setup: kertas A4, orientasi Portrait, margin atas 3 cm, bawah 3 cm, kiri 4 cm, kanan 3 cm.

8

Salin & kumpulkan tautan

Klik Share lagi → Copy link → tempel tautan tersebut ke form/LMS pengumpulan dosen.

Kriteria Pengumpulan
Nama dokumen sesuai format DTD_P09_NIM_NAMA, margin 3-3-4-3 cm, tabel minimal 3×2, minimal 1 gambar, dan tautan share berfungsi.

Rangkuman Pertemuan 9

1
Pengolah kata (word processor) adalah aplikasi untuk membuat, mengedit, dan memformat dokumen — contoh: Google Docs dan Microsoft Word.
2
Format teks dasar meliputi jenis huruf, ukuran, gaya (bold/italic), perataan, dan warna.
3
Layout halaman mencakup margin, orientasi (portrait/landscape), dan ukuran kertas (A4, Letter).
4
Objek seperti gambar, tabel, bentuk, dan grafik dapat disisipkan untuk memperkaya dokumen.
5
Fitur lanjutan seperti Page/Section Break, Styles, Find & Replace, dan shortcut meningkatkan produktivitas secara signifikan.
